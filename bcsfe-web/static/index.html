냥코 대전쟁 세이브 편집

이어하기 코드를 입력하면 세이브를 편집하고 새 코드를 받을 수 있어요. SAVE_DATA 파일을 넣어 바로 편집할 수도 있어요.

게임에서 옵션 → 기종변경으로 코드를 발급하세요. 코드는 한 번만 쓸 수 있어서 편집 후 새 코드를 드려요.

SAVE_DATA 파일을 여기에 놓으세요

또는 클릭해서 선택하세요 — 편집 항목을 비워 두면 세이브 내용만 보여 드려요

      레벨업할 캐릭터

      50+10처럼 레벨+플러스 레벨을 입력하세요. 한쪽을 비우면 그대로 둬요 (예: +10은 플러스 레벨만 바꿔요). 레벨은 캐릭터마다 최대치까지만 올라가고, 캣츠아이 사용도 게임처럼 계산돼요. 보유하지 않은 선택 캐릭터는 함께 추가돼요.

      등급별 추가는 게임 버전에서 획득할 수 있는 캐릭터만 추가해요. 캐릭터를 삭제하면 레벨과 형태도 초기화돼요.

      레전드 · 이벤트

      게임 버전에 있는 모든 맵을 고른 크라운 수까지 클리어해요. 기존 클리어 횟수는 그대로예요.

      안전

      고양이 통조림과 유료 티켓은 계정 정지 위험이 가장 높아요. 경험치, NP, 배틀 아이템, 캐릭터 획득은 비교적 안전해요. 백업은 꼭 보관하세요.

      fieryhenry의 BCSFE-Python 기반 · GPL-3.0 · PONOS와 관련이 없어요.

      사용 방법

      1. 냥코 대전쟁에서 옵션 → 기종변경으로 들어가 이어하기 코드와 인증번호를 메모하세요.
      2. 여기에 입력하고 국가를 고른 다음, 오른쪽에서 바꿀 항목을 선택하세요.
      3. 에디터가 세이브를 내려받아 편집한 뒤 다시 업로드해요. 새 코드가 발급되고, 기존 코드는 한 번 쓰면 더 이상 쓸 수 없어요.
      4. 게임 타이틀 화면에서 기종변경을 누르고 새 코드를 입력하세요.
      5. 되돌리고 싶을 때를 대비해 사이트가 주는 원본 백업을 내려받아 두세요.

      루팅 기기나 에뮬레이터를 쓰시나요? SAVE_DATA로 세이브 파일 탭을 이용하세요. 이 모드에서는 게임 서버에 아무것도 업로드하지 않아요.
